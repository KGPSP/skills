# ADR Template

Use this when a feature introduces a decision worth preserving.

Save as `docs/adr/NNN-[slug].md` when the repository has docs artifacts or the user asks for documentation.

```markdown
# ADR NNN - [Decision Title]

## Status
Accepted | Proposed | Superseded

## Context
[What problem, constraints, and forces led to the decision.]

## Decision
[The chosen approach in direct terms.]

## Consequences
[Positive and negative consequences, including operational impact.]

## Alternatives Considered
- [Alternative] - [why not chosen]

## Verification
- [tests/checks/docs proving the decision works]

## Follow-ups
- [optional future work]
```

Keep ADRs short. They are decision records, not implementation reports.
