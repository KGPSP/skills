**Goal:** ZAP baseline + k6 smoke nightly, supply chain audit clean, release gate defined.

| Day | Task | Owner | Done when |
|---|---|---|---|
| 1 | Setup ZAP baseline in `ci/nightly.yml` against staging URL | dev | ZAP report uploaded as artifact |

| 3–4 | Setup flaky reporting — annotate tests that pass on retry, weekly review | QA lead | dashboard or report exists |

**Exit criterion:** all 7 layers operational (unit + integration HTTP + integration DB + e2e + perf + security + supply chain), release gate enforced, team owns the pipeline.

## Post-pilot — Ongoing

- **Weekly:** review flaky tests, classify (env / timing / real defect).
- **Monthly:** update `CLAUDE.md` + `AGENTS.md` with new conventions discovered.
- **Quarterly:** revisit `qa-strategy.md` — does the tooling decision still hold? (e.g., new Next.js release, new Testcontainers major).
