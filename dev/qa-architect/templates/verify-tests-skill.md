# verify-tests — quality gate runner

> Generated by `qa-architect` for {{PROJECT_NAME}}. Stack: {{STACK}}.

## Procedure

1. **Detect changed paths** (since last commit on current branch):
   ```
   git diff --name-only $(git merge-base HEAD main)..HEAD
   ```

2. **Classify changed files:**
   - `src/components/**`, `app/**` (UI) → require unit + smoke e2e
   - `src/server/**`, `app/api/**`, `services/**` (HTTP) → require unit + integration HTTP
   - `db/**`, repo files with SQL → require integration DB
   - `migrations/**` → require integration DB + manual review
   - configs / CI / docs only → require lint only

3. **Run required layers** (in order, stop on first failure):

   | Step | Command | Stop on fail |
   |---|---|---|
   | Lint | `{{LINT_CMD}}` | yes |
   | Typecheck | `{{TYPECHECK_CMD}}` | yes |
   | Unit | `{{UNIT_CMD}}` | yes |
   | Integration HTTP | `{{INTEGRATION_HTTP_CMD}}` | yes (if HTTP files touched) |
   | Integration DB | `{{INTEGRATION_DB_CMD}}` | yes (if DB files touched) |
   | Build | `{{BUILD_CMD}}` | yes (for UI changes) |
   | Smoke E2E | `{{E2E_SMOKE_CMD}}` | yes (for UI changes) |

4. **Collect artifacts:**
   - `coverage/` (from runner)
   - `reports/junit.xml`
   - `playwright-report/` (if e2e ran)
   - `test-results/` (Playwright trace/screenshot/video on failure)

5. **Report format** (paste raw, do not paraphrase):
   ```
   ## Verify result

   - Lint: PASS|FAIL (exit code, file count)
   - Typecheck: PASS|FAIL
   - Unit: X passed, Y failed, Z skipped
   - Integration HTTP: X passed, Y failed
   - Integration DB: X passed, Y failed
   - Build: PASS|FAIL
   - Smoke E2E: X passed, Y failed
   - Coverage: A% lines, B% branches, C% functions

   ## Failed tests
   (paste raw output)

   ## Flaky tests
   (any test that passed on retry — list with retry count)

   ## Artifacts
   - coverage/index.html
   - reports/junit.xml
   - playwright-report/index.html
   ```

## Anti-rationalization

| Wymówka | Riposta |
|---|---|
| „Wszystkie zmiany w docs, pomijam testy" | Lint always runs. Docs lint też istnieje. |
| „Smoke e2e wolne, pomijam dla UI change" | Smoke = 1 golden flow, < 30s. Pomijanie = brak DoD bramki UI. |
| „Integration DB szybko poprawię later" | „Later" nie istnieje. DB touched → integration DB obowiązkowy. |
| „Coverage spadło, ale tylko 0.5%" | Próg z `configs/{{CONFIG_FILE}}`. Jeśli próg przekroczony — fail. |

## Definition of Done

- Wszystkie wymagane layers pass.
- Coverage threshold met (z `configs/{{CONFIG_FILE}}`).
- Brak flaky testów raportowanych jako PASS (flaky = bug do fix, nie ignored).
- Artefakty istnieją (path do każdego w raporcie).
- Raport ma format z punktu 5.
